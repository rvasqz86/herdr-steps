How you'd use it

  1. When the agent gives you steps, mark the spot, e.g. right-click → "Mark here", or a key. You only mark the start; no need to select the whole range.
  2. The right side opens showing the agent's real output from that mark onward, including your own question and the agent's intro, so you always see how the instructions began.
  3. Lines that look like steps (numbered or bulleted) get a checkbox you can click. Everything else stays as plain text.
  4. The top bar shows the mark name and progress (2/5). Close the side view and reopen it from there later.
